# GPT Adapter

GPT-based agents should use `AGENTS.md` as the canonical project guide.

Session bootstrap:

1. Read `AGENTS.md`.
2. Read `docs/ai/context.md`.
3. Read `docs/ai/session-handoff.md`.
4. Before finalizing, follow `docs/ai/update-protocol.md`.

Do not rely on this adapter as a full source of truth. It exists only to route
GPT-style tooling to the shared agent operating guide.
